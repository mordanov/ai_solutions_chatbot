## Module Responsibilities

### `tests/unit/test_workflow_graph.py` — Graph routing tests

Tests the three conditional routing functions in `workflow/graph.py` with deterministic state inputs. No LLM or external service involved.

```python
# Tests:
# test_route_after_intent_info_query()          → asserts "retrieve_and_generate"
# test_route_after_intent_reservation()         → asserts "reservation_collector_node"
# test_route_after_intent_pricing()             → asserts "dynamic_data_node"
# test_route_after_intent_out_of_scope()        → asserts "out_of_scope_node"
# test_route_after_reservation_validator_submitted() → asserts "approval_request_node"
# test_route_after_reservation_validator_draft() → asserts "respond"
# test_route_after_pending_check_with_draft()   → asserts "guard_rails_node"
# test_route_after_pending_check_no_draft()     → asserts "route_intent"
```

### `tests/unit/test_workflow_nodes.py` — Node function tests (expanded)

Add tests for the 7 nodes not yet covered: `retrieve_and_generate`, `dynamic_data_node`, `out_of_scope_node`, `reservation_collector_node`, `approval_request_node`, `guard_rails_node`, `respond`, `pending_check_node`. Each gets ≥2 tests. LLM, vector store, repository, and approval service all mocked.

### `tests/unit/test_pipeline_integration.py` — Full pipeline test

Exercises the complete path: POST `/chat` (reservation) → in-memory store → POST `/admin/reservation/{id}/approve` → `write_record` called → POST `/chat` (same session) → approved notification returned. Also exercises the rejection path. Uses `httpx.AsyncClient` with `app` (same pattern as `tests/unit/test_approval_api.py`).

```python
# Tests:
# test_full_approval_pipeline()   → storage write called, user gets ✅ notification
# test_full_rejection_pipeline()  → storage write NOT called, user gets ❌ notification
```

### `.github/workflows/ci.yml` — spaCy model download

Add one step after `pip install`:

```yaml
- name: Download spaCy model
  run: python -m spacy download en_core_web_lg
```

### `README.md` — Evaluation results

Replace the "To be populated" placeholder in the Evaluation Results section with actual Recall@5 and Precision@5 values from running `python scripts/evaluate.py` against the seeded knowledge base.
